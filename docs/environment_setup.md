# Environment Setup

Use `requirements-dev.txt` with `venv` for local development, or `environment.yml` with conda. Run `pytest` after installation. Use `requirements-colab.txt` for Google Colab experiments so Colab-managed notebook packages are not reinstalled. Use `requirements-app.txt` only when running the Streamlit or FastAPI prototypes. Use Colab for early GPU experiments and AWS later for reproducible larger runs.
